# Financial Goals Game

A game-style Python program that lets users create financial goals and track progress toward them.

## Features

- Create goals with a name, target amount, and deadline
- Record deposits toward each goal
- View progress as a percentage
- Save goals to a JSON file
- Load saved goals when the program restarts
- Earn XP for completing goals
- Check whether a goal is overdue

## Running the program

```bash
python financial_goals.py
